# Проверка корректности фотографии лица при регистрации

**ВКР Магистратура ТГУ 2026**  
**Автор:** Большова Е.А.  
**Направление:** Компьютерное зрение и нейронные сети
**Кейс:** Проверка корректности фотографии лица при регистрации в Российской государственной библиотеке (РГБ) на соответствие стандартам ICAO 9303 и ISO/IEC 19794-5.

## Описание проекта
Данный сервис реализует каскадный алгоритм для **проверки корректности и нормализации портретных фотографий**. Система анализирует качество изображения, ракурс и наличие перекрытий, преобразуя пользовательские снимки в стандартизированные изображения на однородном фоне, пригодные для печати читательских билетов.

### Ключевые особенности:
*   **Каскадная фильтрация**: Архитектура системы построена по принципу минимизации вычислительных затрат. Ресурсоемкие модели (сегментация фона, оценка качества) активируются только в случае успешного прохождения первичных проверок на освещенность, резкость и ракурс.
*   **Интеллектуальный контроль перекрытий**: Специально обученная нейросеть YOLOv8m-cls детектирует наличие посторонних предметов на лице (медицинские маски, солнцезащитные очки, руки) и головных уборов с точностью 99.3%, обеспечивая соответствие портрета требованиям к документам.
*   **Математический анализ геометрии лица**: Использование 3D-сетки (MediaPipe Face Mesh) позволяет с высокой точностью рассчитывать углы наклона головы (Yaw, Pitch, Roll) и контролировать состояние глаз и рта, отсекая снимки с закрытыми глазами или чрезмерной мимикой.
*   **Нейросетевая нормализация фона (Matting)**: Технология MODNet обеспечивает плавное отделение объекта от сложного фона с сохранением мелких деталей (волос, краев одежды), формируя стандарт на белом фоне.
*   **Интерактивный помощник позиционирования**: Реализован механизм «живых» подсказок в Web-интерфейсе, который в реальном времени анализирует видеопоток и корректирует действия пользователя (например, «Поверните голову прямо» или «Снимите очки») до совершения снимка.
*   **Гарантированная конфиденциальность (Stateless)**: Программа не сохраняет изображения на диске, не извлекает биометрические шаблоны и не производит идентификацию. Обработка данных происходит в оперативной памяти в соответствии с ФЗ-152 «О персональных данных».


## Технологический стек
*   **Backend:** FastAPI (Python 3.12).
*   **Детекция и Сегментация:** YOLOv8-Face, MODNet (ONNX), MediaPipe.
*   **Оценка качества (FIQA):** MagFace (iResNet50).
*   **Классификация:** YOLOv8m-cls.
*   **Инференс:** Оптимизирован для исполнения на **CPU**.

## Подготовка и запуск

### 0. Загрузка весов моделей
Перед запуском необходимо скачать архив с весами нейронных сетей и поместить их в директорию `models/` в корне проекта.

**Ссылка на модели (Google Drive):** [Загрузить веса моделей](https://drive.google.com/drive/folders/1hyFO-FATmQ-v06bUMEOjffYW7t4oY46N?usp=share_link)

**Необходимые файлы в папке `models/`:**
- `yolov8n-face.pt` (Детектор лиц)
- `yolov8m-occlusion.pt` (Классификатор масок, очков и шапок)
- `modnet_photographic_portrait_matting.onnx` (Матирование фона)
- `magface_iresnet50_MS1MV2.pth` (Оценка качества FIQA)
- `antispoofing.onnx` (Antispoofing MiniFASNet-V2. [Ещё в разработке])

### 1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/bolshovaelizaveta/tsu-cv-msc-face-compliance.git
   cd tsu-cv-msc-face-compliance
   ```

### 2. Запуск через Docker 
Использование Docker гарантирует наличие всех системных зависимостей (libgl1, OpenCV).

```bash
# Сборка образа
docker build -t tsu-face-compliance .

# Запуск контейнера (порт 8000)
docker run -p 8000:8000 tsu-face-compliance
```

### 3. Локальный запуск 
Требуется Python 3.12 и установленный `venv`.

```bash
# Создание и активация окружения
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
# venv\Scripts\activate   # Для Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
uvicorn main:app --host 0.0.0.0 --port 8000
```
После запуска сервис доступен по адресу: `http://localhost:8000`

## Структура проекта

```text
tsu-cv-msc-face-compliance/
├── models/             # Веса нейронных сетей (загружаются отдельно)
├── src/                # Логика валидации 
│   ├── config.py       # Пороговые значения ICAO и системные пути
│   ├── detector_v2.py  # Локализация лица и генерация кропов (YOLO)
│   ├── geometry.py     # Анализ ракурса (PnP) и мимики (EAR/MAR)
│   ├── occlusion.py    # Детекция перекрытий и бликов на очках
│   ├── quality.py      # Оценка биометрического качества (MagFace)
│   └── segmentation_v2.py # Удаление фона (MODNet)
├── static/             # Web UI: Интерфейс регистрации в браузере
├── scripts/            # Утилиты для обучения и подготовки данных
├── research/           # Исследовательские модули и бенчмарки
├── docs/               # Проектная документация
├── main.py             # FastAPI сервер и описание каскада
├── Dockerfile          # Спецификация сборки образа
└── requirements.txt    # Список зависимостей
```

## Тестирование и результаты
Эффективность системы подтверждена тестированием на репрезентативном наборе данных (14 232 изображения на базе FFHQ и синтетических деградаций).

**Итоговые метрики:**
- **F1-Score:** 0.984
- **Precision (Точность):** 0.996
- **Recall (Полнота):** 0.973
- **Avg Latency:** ~20 мс, ~300 мс на CPU.
