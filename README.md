# Проверка корректности фотографии лица при регистрации

**ВКР Магистратура ТГУ 2026**  
**Автор:** Большова Елизавета Александровна 
**Направление:** Компьютерное зрение и нейронные сети  
**Кейс:** Проверка фотографии лица при регистрации в Российской государственной библиотеке (РГБ) на соответствие национальным стандартам **ГОСТ Р ИСО/МЭК 19794-5** (Административный регламент МВД РФ № 773) и международным требованиям **ICAO 9303**.

## Описание проекта
Данный сервис реализует каскадный алгоритм для **проверки корректности и нормализации портретных фотографий**. Система анализирует качество изображения, ракурс, направление взгляда и наличие перекрытий, преобразуя пользовательские снимки в стандартизированные изображения на однородном фоне, пригодные для печати читательских билетов.

### Ключевые особенности:
*   **Каскадная фильтрация**: Архитектура системы построена по принципу минимизации вычислительных затрат. Ресурсоемкие модели (сегментация фона, оценка качества MagFace) активируются только в случае успешного прохождения первичных проверок на освещенность, резкость и ракурс.
*   **Двухфакторный контроль перекрытий**: Сочетание обученной нейросети YOLOv8m-cls (маски, очки, шапки с точностью 99.3%) и детектора **MediaPipe Hands** (контроль рук у лица), гарантирующее полное отсутствие посторонних объектов в кадре.
*   **Математический анализ геометрии и взгляда**: Использование 3D-сетки (MediaPipe Face Mesh) позволяет рассчитывать углы наклона головы (Yaw, Pitch, Roll), а также контролировать направление взгляда по двум осям (X и Y), отсекая снимки с закрытыми глазами или отведенным вниз/вбок взглядом.
*   **Адаптивное масштабирование и центрирование**: Интеллектуальный апскейл снимков низкого разрешения (от 300px) до стандарта 640x480 и автоматическое центрирование лица без обрезания макушки.
*   **Нейросетевая нормализация фона (Matting)**: Технология **MODNet** (достигнутый **IoU 92.49%**) обеспечивает плавное отделение объекта от сложного фона с сохранением мелких деталей (волос, краев одежды), формируя стандарт на белом фоне. 
*   **Интерактивная обратная связь в реальном времени**: Реализован механизм «живых» подсказок в Web-интерфейсе, который в реальном времени анализирует видеопоток и корректирует действия пользователя (например, «Поверните голову прямо» или «Смотрите в объектив») до совершения снимка.
*   **Stateless-архитектура и приватность (ФЗ-152)**: Программный комплекс функционирует в режиме без сохранения состояния. Обработка данных, валидация и нормализация происходят исключительно в оперативной памяти (RAM) без записи на диск и извлечения биометрических шаблонов, что гарантирует юридическую чистоту и безопасность персональных данных.

## Технологический стек
*   **Backend:** FastAPI (Python 3.12).
*   **Детекция и Сегментация:** YOLOv8-Face, MODNet (ONNX), MediaPipe.
*   **Оценка качества (FIQA):** MagFace (iResNet50).
*   **Классификация:** YOLOv8m-cls.
*   **Инференс:** Оптимизирован для исполнения на **CPU** (производительность ~6 FPS на одном ядре).

## Подготовка и запуск

### 0. Загрузка весов моделей
Перед запуском необходимо скачать архив с весами нейронных сетей и поместить их в директорию `models/` в корне проекта.

**Ссылка на модели (Google Drive):** [Загрузить веса моделей](https://drive.google.com/drive/folders/1hyFO-FATmQ-v06bUMEOjffYW7t4oY46N?usp=share_link)

**Необходимые файлы в папке `models/`:**
- `yolov8n-face.pt` (Детектор лиц)
- `yolov8m-occlusion.pt` (Классификатор масок, очков и шапок)
- `modnet_photographic_portrait_matting.onnx` (Матирование фона)
- `magface_iresnet50_MS1MV2.pth` (Оценка качества FIQA)
- `antispoofing.onnx` (Antispoofing MiniFASNet-V2. [В режиме логирования])

### 1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/bolshovaelizaveta/tsu-cv-msc-face-compliance.git
   cd tsu-cv-msc-face-compliance
   ```

### 2. Запуск через Docker 
Использование Docker гарантирует наличие всех системных зависимостей (libgl1, OpenCV).

```bash
# Сборка образа
docker build -t tsu-face-compliance .

# Запуск контейнера (порт 8000)
docker run -p 8000:8000 tsu-face-compliance
```

### 3. Локальный запуск 
Требуется Python 3.12 и установленный `venv`.

```bash
# Создание и активация окружения
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
# venv\Scripts\activate   # Для Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
uvicorn main:app --host 0.0.0.0 --port 8000
```
После запуска сервис доступен по адресу: `http://localhost:8000`

## Структура проекта

```text
tsu-cv-msc-face-compliance/
├── models/             # Веса нейронных сетей (загружаются отдельно)
├── src/                # Логика валидации 
│   ├── config.py       # Пороговые значения ГОСТ/ICAO и системные пути
│   ├── detector_v2.py  # Локализация лица и генерация кропов (YOLO)
│   ├── geometry.py     # Анализ ракурса (PnP), мимики (EAR/MAR) и взгляда (X/Y)
│   ├── occlusion.py    # Детекция перекрытий и бликов на очках
│   ├── quality.py      # Оценка качества изображений (MagFace)
│   └── segmentation_v2.py # Удаление фона (MODNet)
├── static/             # Web UI: Интерфейс регистрации в браузере
├── scripts/            # Утилиты для обучения и подготовки данных
├── research/           # Исследовательские модули и бенчмарки
├── docs/               # Проектная документация
├── main.py             # FastAPI сервер и описание каскада
├── Dockerfile          # Спецификация сборки образа
└── requirements.txt    # Список зависимостей
```
